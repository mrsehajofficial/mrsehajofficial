## 🚀 **Flagship Projects** — *Built from Scratch, End-to-End*

### 🛡️ **[Aegis](https://github.com/mrsehajofficial/aegis)** — *Production-Grade Telegram Group Management Bot*
> **The emerald guardian of your Telegram groups** — Deterministic, dependable protection at sub-25ms response times.

```text
┌─ ARCHITECTURE ────────────────────────────────────────┐
│  Python 3.11+  │  python-telegram-bot v21+           │
│  SQLAlchemy 2.0 │  AsyncIO (aiosqlite & asyncpg)     │
│  Sliding-window anti-flood  │  Regex anti-spam       │
│  Telegram Business auto-reply  │  Role-based admin   │
│  Docker + CI/CD  │  AGPL-3.0 Open Source             │
└────────────────────────────────────────────────────────┘
```

**🔥 Key Capabilities:**
- **Smart Anti-Flood** — In-memory sliding windows (5 msgs/3s default), instant mute/restrict
- **Content Locks** — Regex patterns, URL filtering, media restrictions, custom blacklists
- **Business Automation** — Private chat auto-replies, greeting responders, OOO fallbacks with cooldowns
- **Interactive Setup Wizard** — `python -m app.setup` gets you running in 60 seconds
- **Live Demo Console** — Try commands at [aegis.wasmer.app](https://aegis.wasmer.app)
